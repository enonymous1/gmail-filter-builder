Gmail filters, filled out — not decoded from Settings.

Fill in what a message matches, check off what Gmail should do with it, and stack up as many filters as you need. Then download one file and import it straight into Gmail. Everything happens in this page — no account, no sign-in.

How the round trip works

  1. Import (optional) — already have filters? Export them from Gmail and bring them in here first.
  2. Build — pick what a filter matches and what it does.
  3. Export — download the gmail-filters.xml file this page generates.
  4. Import — in Gmail: Settings → See all settings → Filters and Blocked Addresses → Import filters, choose the file, done.

The export uses Gmail’s own filter file format — the same one Gmail produces under “Export filters” — so it imports cleanly and can be re-exported later.

Import filters

      
    

    
Bring in a Gmail filter export (mailFilters.xml) — from Settings → Filters and Blocked Addresses → Export. Imported filters are added to your list; the starter examples are replaced when any filters come in. Duplicates are not detected, and entries the app can’t read are reported, not swallowed.

    
    

      
      
    

    

      
      
    

  

  
  
    

      
Security check

      
    

    
A heuristic review of the filters in this list — it flags patterns an account takeover leaves behind. It never changes or deletes anything; you decide what to do with each finding. It can’t tell which forward addresses are yours, so review any address you don’t recognize. Nothing leaves this page.

    

    

    

      
    

  

      
How the round trip works

      

        
1
Export your existing filters Optional
Only if you want to start from filters you already have: in Gmail, Settings → Filters and Blocked Addresses → Export, then Import Filters here to see, edit, and add to them.

        
2
Download the file
Use the Download button above. You’ll get gmail-filters.xml with every filter in your list.

        
3
Open Gmail settings
In Gmail on desktop: gear icon → See all settings → Filters and Blocked Addresses tab.

        
4
Import & create
Click Import filters, choose the file, then Create filters. Tick “Also apply filter to matching conversations” there if you want it to clean up mail you already have.
