How the round trip works

  1. Build — pick what a filter matches and what it does.
  2. Export — download the gmail-filters.xml file this page generates.
  3. Import — in Gmail: Settings → See all settings → Filters and Blocked Addresses → Import filters, choose the file, done.

The export uses Gmail’s own filter file format — the same one Gmail produces under “Export filters” — so it imports cleanly and can be re-exported later.

Getting them into Gmail

      

        
1
Download the file
Use the Download button above. You’ll get gmail-filters.xml with every filter in your list.

        
2
Open Gmail settings
In Gmail on desktop: gear icon → See all settings → Filters and Blocked Addresses tab.

        
3
Import & create
Click Import filters, choose the file, then Create filters. Tick “Also apply filter to matching conversations” there if you want it to clean up mail you already have.
